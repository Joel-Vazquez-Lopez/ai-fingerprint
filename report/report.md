## 1. Introduction

My aim with this project is to investigate if short writing samples can be classified according to their source. The main task is to distinguish between human written text, human text polished with AI, and responses generated by several AI systems. From that my motivation became to observe if AI-generated text has certain patterns that can be recognisable within two constraints (small dataset and simple models). 

The project includes two related classification settings. The first is a seven-class source classifier with the labels `human_original`, `human_ai_polished`, `chatgpt`, `claude`, `deepseek`, `gemini`, and `grok`. This is the main embedding-based classifier. The second is an AI-only attribution experiment that compares only AI model labels. This extension helps test whether different AI systems leave distinguishable writing patterns.

In addition to this my first idea was to do an embedding system that could classify between the style of people based on the music they like, something that typically Spotify would do, however I believe that the system that I created with that idea didn't worked as good in relation with embedding systems, thus I decided to keep it as a side project, you can see it in the following repositories:

## 2. Dataset

The dataset was handmade from prompts answered by several sources. It includes 400 responses from each ChatGPT, Claude, Gemini, Grok, and DeepSeek, together with human written answers (only by one annotator) and human written answers polished with AI (200 each). The processed files are split into training and test sets, stored under `data/processed/`. 

The project also includes an expanded AI-only dataset for model attribution. This second dataset focuses on distinguishing between AI systems rather than separating human and AI text. Creating both datasets made it possible to compare a broad authorship task with a narrower AI-model attribution task. The total data size is of 3400 text samples. (I spent two days only with this, using each of the AI chat interfaces),

## 3. Embeddings And Classifiers

The main classifier uses sentence embeddings from `sentence-transformers/all-MiniLM-L6-v2`. These embeddings represent each text as a dense semantic vector. Several classifiers were trained and evaluated, including Logistic Regression, Linear SVM, Random Forest, and MLP. The best model for the seven class task was the MLP classifier.

For comparison, I realized that an embedding system captures meaning through syntax and semantics wouldn't be good enough based on this task so I decided to train an AI-only TF-IDF model with Linear SVM. And the result is that it performed strongly because it captures stylistic signals like punctuation, repeated phrase patterns, and small lexical habits. 

## 4. Results

The models were evaluated using accuracy, macro F1 and a basic random baseline. Accuracy measures the overall percentage of correct predictions, while macro F1 gives equal weight to each class, which is important because the project compares multiple source labels rather than a simple binary decision. The results were also compared with a random baseline: 14.29% for the seven class task and 20.00% for the five class AI-only task.

### Seven class classifier

The main embedding classifier was trained on the seven class dataset containing `human_original`, `human_ai_polished`, `chatgpt`, `claude`, `deepseek`, `gemini`, and `grok`. The best model was the MLP classifier, which achieved 50.71% accuracy and 50.54% macro F1.

| Model | Accuracy | Macro F1 |
|---|---:|---:|
| MLP classifier | 50.71% | 50.54% |
| Linear SVM | 48.21% | 48.09% |
| Logistic Regression | 47.14% | 46.91% |
| Random Forest | 33.21% | 32.37% |
| Random baseline | 14.29% | - |

These results show that sentence embeddings contain meaningful signal for distinguishing between human-written, AI-polished, and AI-generated text. However, the task remains difficult because the model must separate both human/AI differences and differences between individual AI systems, despite that it performs nicely to distinguish between human and AI. 

### AI-only embedding attribution

The second experiment focused only on AI-generated text from five systems: ChatGPT, Claude, DeepSeek, Gemini, and Grok. The best embedding  model was Logistic Regression, which achieved 47.50% accuracy and 47.30% macro F1.

| Model | Accuracy | Macro F1 |
|---|---:|---:|
| Logistic Regression | 47.50% | 47.30% |
| Linear SVM | 46.50% | 46.38% |
| MLP classifier | 46.50% | 46.18% |
| Random Forest | 34.50% | 34.09% |
| Random baseline | 20.00% | - |

This result suggests that sentence embeddings capture some model specific writing patterns, but not enough for highly reliable classify. The overlap between modern AI systems makes this task challenging when using semantic embeddings alone.

### AI-only TF-IDF attribution

The strongest overall result came from the AI only TF-IDF model with Linear SVM. This model achieved 84.50% accuracy and 84.40% macro F1.

| Model | Accuracy | Macro F1 |
|---|---:|---:|
| Character TF-IDF + Linear SVM | 84.50% | 84.40% |
| Random baseline | 20.00% | - |

My theory is that AI model attribution may depend more on surface-level writing fingerprints than on semantic meaning alone. Since we can capture punctuation habits, formatting patterns, repeated phrase structures, capitalization, and other local style signals that sentence embeddings may smooth over.

Overall, I observed that embeddings are really useful for classification systems, especially when compared with the random baseline. However, the TF-IDF result suggests that the best feature representation depends on the exact task: semantic embeddings are useful for general source categories, while local character level features can be stronger for distinguishing between AI model fingerprints.

## 7. Limitations And Future Work

The classifier should not be interpreted as proof of authorship. It learns patterns from the collected dataset and may fail on very short texts, translated texts, heavily edited writing, future model versions, or models not included in training. The predictions should be treated as signals rather than definitive evidence.

Future work could expand the dataset, include more AI systems and from older versions, collect more human writing samples adding different annotators, evaluate robustness across prompt types, and test whether combining embeddings with character-level features improves performance. Also an idea that I have in mind would be to have an automatic system that would be able to do it on a dynamic way to always have consciousness of the last updates done. 

Overall I am happy that I was able to achieve some signal, as it is well known all the LLM's after all use similar dataset and the objective is to produce similar outputs, so being able to see that even robust systems can be recognizable was really educative and interesting.
